# Pipelines to annotate variants and estimate genetic diversity across different varaint impact categories


Used two pipelines with different software to annotate the variants. Then count number of heterozygous sites per samples in different annotated categories based on variant impact.

- Variant Effec Predictor (annotation in `annotate_vep` folder, and estimation of diversity across different annotated categoreis in `load_annotation` folder)

- snpEff (both annotation and estiamtion of genetic diversity in `load_snpeff` folder)
